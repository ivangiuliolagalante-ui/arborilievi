ArboRilievi v3 – Android e iPhone

1. Apri https://github.com/ivangiuliolagalante-ui/arborilievi
2. Carica i file della presente cartella nella radice del repository, sovrascrivendo quelli esistenti. Carica anche icon-192.png e icon-512.png.
3. Premi Commit changes. Verifica Settings > Pages, branch «principale», folder /(root).
4. Apri https://ivangiuliolagalante-ui.github.io/arborilievi/?v=3 su Chrome Android o Safari iPhone.
5. Android: menu ⋮ > Installa app / Aggiungi a schermata Home. Autorizza Posizione e Fotocamera.
6. Esegui un rilievo di prova senza foto e poi con foto. Esporta periodicamente backup JSON.

Avvertenze: i dati si trovano nel browser del dispositivo, non nel repository GitHub. Non cancellare dati sito. Le foto aumentano la dimensione dei backup. Android e iPhone non si sincronizzano automaticamente.
